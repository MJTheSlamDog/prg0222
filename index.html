1. Programming Languages, Hardware & Platforms

Major Paradigm Classifications

  • Procedural Programming: Follows a sequential step-by-step series of commands or procedures to reach an output (e.g., C, Pascal, BASIC)[cite: 1].
  • Object-Oriented Programming (OOP): Structures programs around reusable "objects" encapsulating data attributes and operations/methods (e.g., Java, Python, C++)[cite: 1].
  • Functional Programming: Evaluates mathematical functions using immutable data and higher-order execution (e.g., Scala, Haskell, Erlang)[cite: 1].
  • Scripting Languages: Automates repetitive operations, handles dynamic web content, or connects server processes (e.g., Bash, PHP, Node.js)[cite: 1].
  • Logic Programming: Solves queries using declared facts and conditional logic rules (e.g., Prolog, Datalog)[cite: 1].

Hardware vs. Software Dynamics

Computing platforms rely on hardware and software acting complementarily[cite: 1]. Hardware provides tangible infrastructure, while software supplies instructions[cite: 1]. Key internal hardware components include:

  • CPU (Central Processing Unit): Known as the core engine or "brain" that processes and executes binary instructions[cite: 1].
  • Motherboard: The primary circuit board acting as a central hub interconnecting processing unit, memory, and expansion slots[cite: 1].
  • RAM vs. Storage: RAM delivers temporary, volatile workspace cleared upon powering down; hard drives and SSDs supply non-volatile, persistent storage for programs and system data[cite: 1].
  • Heat Sink: A passive thermal element installed directly over high-heat hardware (like the CPU) to regulate working temperatures[cite: 1].

2. Software Development Tools & Libraries

Developer Toolsuite Spectrum

  • Collaborator: Peer code and document review suite providing electronic signatures for regulatory standards like ISO26262[cite: 1].
  • RAD Studio: High-productivity IDE compiling native cross-platform applications (Windows, macOS, iOS, Android, Linux) from a single codebase via direct FireDAC database engine connections[cite: 1].
  • FinanceLayer: Real-time API service delivering automated financial news feeds and live stock metrics formatted in JSON payloads[cite: 1].
  • Studio 3T: Advanced MongoDB management client featuring Visual Query Builder, data masking obfuscation, and SQL-to-NoSQL migration workflows[cite: 1].
  • Linx: Low-code server/IDE platform utilizing visual drag-and-drop workflow designers to build automated backend processes and expose web services[cite: 1].
  • SQL Sentry: Enterprise database performance monitoring system providing root-cause analysis, storage capacity forecasting, and scheduled job oversight via an Outlook-style calendar[cite: 1].

Libraries vs. Frameworks

Structural Comparison:
  • Library: A collection of pre-written functions or routines designed to solve specific problems[cite: 1]. The developer remains in full control of program architecture and invokes library components as needed (like buying loose furniture to customize a room)[cite: 1].
  • Framework: A complete architectural blueprint and mandatory structure that controls execution flow[cite: 1]. Developers must fit custom code into the framework's preset patterns (like decorating a pre-built model home)[cite: 1].

Key Data Science Libraries

  • NumPy: Python library specializing in multidimensional array manipulation for optimized scientific processing[cite: 1].
  • Matplotlib: Python plotting tool configured to render visual graphs and data timelines[cite: 1].
  • TensorFlow: Google-developed library designed to build, optimize, and train deep neural networks[cite: 1].
  • Apache Spark: Distributed analytics engine executing fast queries over massive datasets across Scala, Python, Java, and SQL[cite: 1].

3. Data Structures, Algorithms & Syntax

Data Structure Classifications

  • Linear Structures: Elements are ordered sequentially[cite: 1].
    • Arrays: Fixed, continuous memory blocks storing identical data types[cite: 1].
    • Stacks: Operates on a Last-In, First-Out (LIFO) protocol where elements enter and exit from a single top position[cite: 1].
    • Queues: Operates on a First-In, First-Out (FIFO) protocol where items join at the rear and exit from the front[cite: 1].
    • Linked Lists: Dynamic elements (nodes) connected via pointer references to memory addresses[cite: 1].
  • Non-Linear Structures: Hierarchical or interconnected element organization[cite: 1].
    • Trees: Collections of connected nodes with a single root and unique paths between vertices[cite: 1].
    • Graphs: Complex networks formed by vertices connected through directed or undirected edges[cite: 1].

Algorithmic Classifications

An algorithm is a finite sequence of precise instructions executing inputs to produce deterministic outputs[cite: 1]. Key types include:

  • Divide & Conquer: Splits a problem into smaller sub-problems, solves each, and recombines the results[cite: 1].
  • Brute Force: Systematically tests every possible combination until finding a match[cite: 1].
  • Greedy: Selects the locally optimal choice at each sequential step aiming for a global optimum[cite: 1].
  • Dynamic Programming: Breaks complex tasks into overlapping sub-problems, solving each once and caching results[cite: 1].

4. Logical Flow & Error Handling

Boolean Logical Operators

Programs direct flow using Boolean expressions evaluated via logical operators[cite: 1]:

  • AND (&& / and): Returns true only if both operands evaluate to true[cite: 1].
  • OR (|| / or): Returns true if at least one operand evaluates to true[cite: 1].
  • NOT (! / not): Inverts the Boolean truth value of an expression[cite: 1].

Categorization of Software Errors

  • Syntax Errors: Violations of language structural grammar rules caught before runtime or execution (e.g., missing bracket/semicolon)[cite: 1].
  • Logic Errors: Flaws in implementation logic that run without throwing errors but produce incorrect output[cite: 1].
  • Compilation Errors: Occur when the compiler fails to transform high-level code into low-level machine instructions[cite: 1].
  • Runtime Errors: Faults encountered during active program execution (e.g., trying to read an unassigned null variable)[cite: 1].
  • Arithmetic Errors: Invalid numerical calculations occurring during evaluation (e.g., division by zero)[cite: 1].
  • Resource Errors: Occur when software exceeds system resource allocations, such as infinite loops exhausting memory[cite: 1].

Parity Bits & Error Detection

Data transmission uses additional parity bits appended to binary payloads to detect data corruption[cite: 1]:

  • Even Parity: The parity bit is set to 0 or 1 so the total count of '1' bits across the byte is an even number[cite: 1].
  • Odd Parity: The parity bit is configured so the total count of '1' bits across the byte remains an odd number[cite: 1].

2.10 Describe how Parity Bits are utilized in data communications to detect bit corruption during transmission.[cite: 1]
Model Answer:
• An extra bit (parity bit) is appended to a data byte so that the total count of 1-bits is fixed to an Even or Odd count[cite: 1].
• On receipt, the system counts the 1-bits[cite: 1]. If an Even parity stream arrives with an odd count of 1s, corruption is flagged and retransmission requested[cite: 1].
